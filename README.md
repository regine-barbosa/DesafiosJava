# 💚 Bootcamp Elas+ Tech — Trilha Back-end 🚀  

Este repositório faz parte das atividades do **bootcamp Elas+ Tech**, uma iniciativa exclusiva para mulheres, promovida pela **Ada Tech** como um dos projetos pilotos do programa **Caixa: Desafio Mulheres em STEM**, realizado pelo **Fundo Socioambiental CAIXA** em parceria com a **Artemisia**.

---

## Sobre este repositório
Espaço exclusivo para para reunir **exercícios de prática da linguagem Java (gerados por IA)** além de projetos derivados da trilha de **Back-end** do bootcamp.  
O conteúdo será atualizado ao longo da jornada, acompanhando meu progresso no programa.
